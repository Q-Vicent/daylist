# 日序 Daylist

把重要的日子放在眼前。用于整理考试、竞赛、报名与校园活动，重点展示距离截止还有多少天。后续计划接入从 QQ 收集的活动信息。

## 已实现

- 活动卡片与排行榜两种视图。
- 按分类、关键词筛选，按重要性、截止时间排序。
- 添加活动、关注与取消关注、删除自建活动。
- 手机与桌面适配。
- 自建活动与关注保存在当前浏览器，不跨设备同步。

转专业相关日期及学校日程由用户提供，具体安排请以学校通知为准。目前不包含 QQ 接入、后台自动采集或系统通知推送。

## 本地使用

直接打开 `index.html`，或用任意静态服务器托管本目录。无需安装依赖或构建。

运行逻辑检查（需要 Node.js）：

```sh
node --check app.js
node check.cjs
```

剩余时间按距目标时间的 24 小时向上取整；不足 24 小时显示 1 天，到达目标时间显示「已截止」。页面每分钟及重新切回页面时更新。展示日期采用北京时间，新增活动的输入时间采用浏览器本地时区。

## 静态部署与子域名

所有网页文件位于仓库根目录，入口为 `index.html`。可以使用支持自定义域名的静态托管服务。

以 Cloudflare Pages 为例：

| 配置 | 值 |
| --- | --- |
| GitHub 仓库 | `Q-Vicent/daylist` |
| 生产分支 | `main` |
| 框架预设 | 无 |
| 构建命令 | `exit 0` |
| 输出目录 | `.` |

部署完成后，在托管服务中添加你的子域名，并按该服务提供的记录配置 DNS。域名尚未确定，因此仓库不包含写死的自定义域名。

参考：[Cloudflare 静态 HTML 部署文档](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)。

## 文件

- `index.html`：页面结构。
- `style.css`：样式与响应式布局。
- `app.js`：活动数据、倒计时与交互逻辑。
- `check.cjs`：核心逻辑检查。
